# 关于我 / About Me

你好！我是 **Re0XIAOPA**，一名软件工程专业的开发者。

比起复杂的装饰，我更倾向于干净的代码与纯粹的页面设计。我习惯使用前端技术栈构建优雅的交互，并运用后端语言编写健壮的业务逻辑。

在业余时间，我喜欢参与开源或编写有趣的 Web 页面。
