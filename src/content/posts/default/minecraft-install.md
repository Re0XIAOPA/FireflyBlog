欢迎来到本篇教程！本文面向所有想要加入方块酒馆服务器的新人，从零讲解启动器安装、整合包导入、服务器登录注册全套流程。
官方文档参考：[https://docs.blocktavern.cn/](https://docs.blocktavern.cn/)

> ⚠️ 重要提示：服务器必须使用官方配套整合包，私自增减模组会导致无法进入服务器、游戏崩溃、物品异常！

## 一、游玩前置要求
1. 操作系统：推荐 Windows 10 / Windows 11
2. 内存：最低 4GB，建议分配 8GB 内存游玩
3. 文件路径：游戏、启动器存放文件夹**严禁包含中文、空格**
    - ✅ 示例：`D:\MC\BlockTavern`
    - ❌ 禁止：`D:\游戏\方块酒馆`

## 二、选择并安装启动器（优先PCL2）
提供两款主流启动器，任选其一即可，推荐新手使用 **PCL2**。

### 方案1：PCL2 启动器（推荐）
1. 前往方块酒馆文档下载页面获取 PCL2 压缩包
2. 解压至纯英文路径，不要直接解压在桌面
3. 运行 `PCL.exe`，首次打开启动器会自动检测 Java
4. 如果缺少运行环境，启动器可一键自动安装 Java 17

### 方案2：HMCL 启动器（备用）
1. 在文档下载中心下载 HMCL 压缩包
2. 解压后运行主程序
3. 若无Java环境，需要手动配置 Java 17

## 三、导入方块酒馆官方整合包
1. 从官方文档下载最新整合包（`.zip` 文件，**不要手动解压**）
2. PCL2操作：
    - 切换到【版本】页面 → 左下角【导入整合包】
    - 选中下载好的整合包压缩包，确认导入
    - 等待启动器自动下载游戏、Fabric加载器、全部模组
3. HMCL操作：直接将整合包压缩包拖拽进窗口自动安装

导入完成后，版本列表出现 `BlockTavern` 相关版本代表成功。

## 四、账号设置与启动游戏
启动器提供三种登录方式，按需选择：
- **第三方皮肤站登录**：前往 [LittleSkin](https://littleskin.cn/) 注册账号，可自定义游戏皮肤，注册完成后返回启动器登录。
- **离线登录（大部分玩家）**：填写英文ID（仅字母、数字，不能中文），ID就是游戏内名称。
- **微软正版登录**：选择微软登录，浏览器授权账号，自动加载正版皮肤。

选择整合包版本，点击启动游戏，等待游戏加载完成。

## 五、连接服务器 & 账号注册
1. 游戏主菜单 → 多人游戏 → 添加服务器
> 💡 部分整合包已预先内置服务器IP，可直接双击进入。
2. 服务器信息填写
    - 名称：方块酒馆（自定义）
    - 地址：`mc.blocktavern.cn`

> 如果地址失效可以进官方社群咨询最新IP

3. 保存服务器，双击进入
4. **首次进入需要注册账号**，在聊天框输入指令：/register 你的密码 重复密码  
示例：`/register 666888 666888`

5. 后续登录服务器输入登录指令：
/login 你的密码

> 忘记密码可以查阅官方文档FAQ寻找解决方案。

## 六、服务器常用指令
更多指令详见官方文档指令列表：https://docs.blocktavern.cn/指令列表

/sethome 设置家  
/home 传送回家  
/res create 领地名称 创建领地  
/rules 查看服务器规则  

> 进服前务必阅读服务器规则，违规将会受到处罚！

## 七、常见问题排查
### 1. 游戏崩溃、黑屏
- 检查文件夹路径是否存在中文
- 在启动器设置重新安装Java17
- 适当调高游戏分配内存（建议3072MB以上）
- 可在官方社群下载修复模组缓解崩溃；该模组会不定期更新，遇到崩溃尽量提交问题，方便维护人员修复。

### 2. 无法连接服务器
- 确认IP地址输入正确：`mc.blocktavern.cn`
- 关闭电脑防火墙尝试，或切换手机热点测试
- 确认使用官方完整整合包

### 3. 提示模组缺失
请勿自行修改模组！重新下载官方整合包覆盖安装。
